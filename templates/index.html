Email DFA – State Transition Diagram

q0 is the initial state. q5 is an accepting state. The automaton checks the username, @ symbol, domain and extension.

q1

q0: Reads the first character of the username.

q1: Reads remaining username characters and @.

q2: Reads the first domain character.

q3: Reads domain characters.

q4: Reads the first extension letter.

q5: Accepting state after a valid extension.

Reject: Invalid characters or incorrect email structure.
